# Synthehol 0.1.0

The first public Synthehol prerelease makes Windows Steam games approachable on
Apple Silicon Macs without requiring users to assemble Wine wrappers by hand.

## Highlights

- Create and manage isolated Wine configurations from a native macOS app.
- Download a checksum-verified Wine runtime and install Steam from Synthehol.
- Browse installed games and owned games available to install in a poster grid.
- Use Windows games from the regular macOS Steam client with the embedded,
  NotProton-derived Synthehol Steam Play compatibility layer.
- Configure graphics backends, sync modes, Windows versions, mapped drives,
  artwork, and per-game launch options.
- Open Wine and compatibility logs for troubleshooting crashes and hangs.
- Import Apple's Game Porting Toolkit 4 libraries for D3DMetal support.

## Requirements

- Apple Silicon Mac (M1 or newer)
- macOS 15 or newer
- Rosetta 2
- macOS 27 or newer for Game Porting Toolkit 4 / D3DMetal

Game Porting Toolkit 4 is not included. Download it separately from Apple and
use **Settings → Graphics → Import GPTK 4…**. The current importer accepts GPTK
4 beta 2 or newer.

## Installation

Download `Synthehol-0.1.0-macOS.dmg`, open it, and drag Synthehol to Applications.
This prerelease is Developer ID signed but not yet notarized. If macOS blocks the
first launch, approve Synthehol in **System Settings → Privacy & Security**.

Compatibility varies by game, and Steam or macOS updates may temporarily affect
the native Steam integration. Back up important saves before testing.

Synthehol's native Steam support incorporates and extends components from
[NotProton](https://github.com/NotProtonNot/NotProton). Users do not need to
install NotProton separately. Upstream licenses and notices are included in the
repository and application payload.
