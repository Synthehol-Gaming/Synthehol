# Synthehol 0.1.1

This release fixes native Steam cloud-save handling and D3DMetal startup and
rendering, and adds per-game performance profiles.

## Changes

- Fix Windows Steam Cloud save paths by registering Synthehol Steam Play with
  the compatibility-tool name Steam expects.
- Merge compatible Windows user-profile folders after cloud saves download,
  retaining a backup and refusing to overwrite conflicting saves.
- Use a separate D3DMetal runner with matching Apple DXGI and Direct3D bridge
  modules. This fixes the diagnosed Palworld DX12 startup crash and missing
  geometry while preserving the normal runner for other graphics backends.
- Add Compatibility, Balanced, and Maximum FPS per-game performance profiles,
  enabled only when the runtime advertises the required capabilities.
- Support importing checksum-verified local performance runtimes and include
  tooling and licensed patches for assembling the optional performance runtime.
- Improve native Steam game settings, diagnostics, and compatibility controls.

## Upgrading

Replace the previous app with Synthehol 0.1.1, then use **Install or Repair** on
the **Mac Steam** page. Fully quit and reopen Steam to load the updated tool.
Reselect **Synthehol Steam Play** in affected games' **Properties → Compatibility**
settings if they still reference the previous tool. Let cloud sync finish before
playing. For Palworld, select D3DMetal and launch with DirectX 12.

## Requirements and installation

- Apple Silicon Mac (M1 or newer), macOS 15 or newer, and Rosetta 2.
- macOS 27 or newer for Game Porting Toolkit 4 / D3DMetal.
- Import your own Game Porting Toolkit 4 beta 2 or newer for D3DMetal; Apple’s
  libraries are not included in the download.

Download `Synthehol-0.1.1-macOS.dmg`, open it, and drag Synthehol to Applications.
This early release is Developer ID signed but not notarized. If macOS blocks
the first launch, approve it in **System Settings → Privacy & Security**.

Compatibility varies by game. Upstream licenses and notices are included in
the repository and application payload.
